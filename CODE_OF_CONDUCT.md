# Code of Conduct

AI CONTROL GRID aims to maintain a professional, technically rigorous, and welcoming open-source community.

Participants are expected to:

- discuss ideas and code on their technical merits;
- give actionable, respectful review feedback;
- avoid harassment, discrimination, threats, or personal attacks;
- respect privacy and confidentiality;
- avoid publishing credentials, private data, or exploit details that could harm users;
- acknowledge mistakes and correct them constructively.

Disagreement is normal. Repeated disruptive behavior, harassment, doxxing, spam, or deliberate security abuse may result in moderation or loss of participation privileges.

Concerns about community conduct may be raised privately with the primary maintainer through the repository owner's GitHub profile.
