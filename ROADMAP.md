# AI CONTROL GRID Roadmap

This roadmap describes current open-source priorities. It is directional rather than a promise of delivery dates.

## Current priorities

### 1. OSS foundation and reproducible deployment

- documented local setup and deployment paths;
- stable CI/regression gates;
- release/versioning discipline;
- contributor and security workflows;
- smaller, easier-to-evaluate example environments.

### 2. Governance engine quality

- jurisdiction-aware governance profiles;
- policy-registry validation;
- source verification for legal and regulatory references;
- explainable governance decisions;
- deterministic regression cases for high-risk decisions.

### 3. Runtime AI oversight

- telemetry ingestion and evaluation;
- policy thresholds and escalation;
- incident deduplication and prioritization;
- reviewer exceptions and human override capture;
- model/provider-agnostic runtime adapters.

### 4. Enterprise identity and tenancy

- SAML/OIDC hardening;
- organization-domain controls;
- invitation and JIT workflows;
- tenant-isolation regression coverage;
- audit and retention improvements.

### 5. Integrations and SDKs

- telemetry SDK improvements;
- integration connectors;
- example adapters for common AI gateways and platforms;
- clearer extension contracts for community integrations.

## Good first contribution areas

Contributors looking for a contained starting point are encouraged to help with:

- documentation clarity;
- regression tests;
- accessibility;
- example integrations;
- developer tooling;
- issue reproduction;
- deployment documentation.

Larger architectural work should begin with an issue so scope and security implications can be discussed first.
